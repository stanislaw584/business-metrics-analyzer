# Бизнес-требования к приложению Business Metrics Analyzer

## Цель

Автоматизировать расчёт ключевых показателей эффективности (KPI) предприятия и их визуализацию, чтобы руководитель получал сводку без ручной работы в таблицах.

## Пользователи

- Руководитель: просматривает итоговые показатели и графики.
- Аналитик: загружает данные о выручке и затратах, проверяет расчёты.

## Функциональные требования

1. Загрузка данных о выручке и затратах по месяцам.
2. Расчёт средней выручки за период.
3. Расчёт рентабельности в процентах.
4. Построение графика динамики выручки.

## Нефункциональные требования

- Запуск на Python 3.12+ без сложной настройки (через `requirements.txt`).
- Корректная обработка нулевой выручки (без деления на ноль).
- Проект хранится в Git, изменения вносятся через Pull Request.
